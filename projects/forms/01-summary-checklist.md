# 프로젝트 요약 (1페이지) 필수 항목

## 📐 기본 형식
- [ ] 프로젝트 요약: 1페이지
- [ ] 파란색 안내 문구는 모두 삭제

---

## 📝 프로젝트 요약 작성 항목

### 1. 프로젝트명 (서비스명)
- [ ] 직관적인 한 줄 요약 (서비스명 명시)
- [ ] 예시: (당근마켓) 당신 근처의 따뜻한 중고 직거래 어플
- [ ] 웹사이트 마이페이지에 반영될 최종 프로젝트명

### 2. 프로젝트 소개
- [ ] 3줄 이내로 작성
- [ ] 프로젝트의 목적과 개념을 명확히

### 3. 기술 키워드
- [ ] 머신러닝, 딥러닝, LLM, 블록체인 등 적용 기술 명시
- [ ] 3~5개 키워드

### 4. ICT 연구개발 기술 분류
- [ ] 대분류 선택 (①)
- [ ] 중분류 선택 (②)

### 5. 팀 정보
- [ ] 팀명 기입
- [ ] 팀원 이름 명시

### 6. 목적 및 필요성
- [ ] 문제인식과 기획의도 간단히 작성

### 7. 프로젝트 개요
- [ ] 주요 기능과 차별화 요소 간단히 작성

### 8. 프로젝트 수행방안
- [ ] 월별 추진일정 요약
- [ ] 개발내용 요약

### 9. 결과물 활용방안 및 기대효과
- [ ] 간단한 설명

## 🌐 외부 후기 반영 추가 체크

> SWM 11·13·15·16기 후기에서 1p 요약본·발표 첫 페이지에 자주 지적된 항목.

- [ ] **프로젝트명 카피가 "(서비스명) 한 줄 가치 제안" 포맷을 따르는가?**
  - 예: `(당근마켓) 당신 근처의 따뜻한 중고 직거래 어플`
  - 신문기사 헤드라인처럼 읽혀야 함.
- [ ] **마이페이지에 등록된 최종 프로젝트명과 일치하는가?** (양식 안내)
- [ ] **발표 PPT 첫 페이지의 한 줄과 동일한가?** (자료 간 일관성)
- [ ] **3줄 프로젝트 소개에 "누구를 위해 / 무엇을 / 어떻게"가 다 들어 있는가?**
- [ ] **기술 키워드에 AI 관련 키워드가 1개 이상 있는가?**
  - 17기는 "AI·SW마에스트로". AI 비중에 대한 기대치가 높음.
- [ ] **본문(02-main.md)의 차별점 한 문장이 요약본에 동일하게 들어 있는가?**
  - 본문↔요약 일관성. 면접 첫 30초 톤을 결정.
