# constraints — 금지 사항과 에러 처리

전 과정에서 지켜야 하는 규칙. 체크리스트로 사용.

## 추측 금지

다음 항목은 RAW DATA에 근거가 없으면 **만들어내지 않는다**. 사용자에게 묻거나 인라인 추가논의로 누적.

- 시장 규모 수치 (예: "5조 원 시장", "연 12% 성장")
- 사용자 통계 (예: "30대 직장인 80%가 OOO를 겪음")
- 경쟁사 가격·점유율
- 라이브러리 정확 버전·동작 (예: "OOO v3에서 ~를 지원")
- 멘토 코멘트
- 팀원 보유 기술·경험 (RAW에 적힌 것만)
- 데이터셋 정확 라이선스
- 정부·기관 정책 세부 내용

근거가 없는데 본문에 필요하면 셋 중 하나:
1. 사용자에게 묻는다.
2. `[⚠ 확인 필요]` 태그로 placeholder만 두고 다음 진행.
3. 인라인 추가논의에 `#DD-N [근거 부족]` 누적.

## 마스킹

- **디스크 쓰기 단계에서만** 적용. 사용자 질문이나 내부 합본 RAW에는 적용 X.
- 적용 대상: 본명, 전화번호, 이메일, 슬랙 핸들, 카카오톡 ID, 개인 식별 소속 정보.
- 멘토 이름도 마스킹 대상 (예: `OOO 멘토`). 다만 멘토 직책(예: "백엔드 멘토")은 유지.

## 자동 생성 금지

- `projects/inputs/<new-project>/` 같은 부모 디렉터리는 사용자가 명시적으로 `mkdir`. 본 skill이 만들지 않는다.
- 다만 `projects/outputs/<project>/<ts>-proposal/` 타임스탬프 자식 디렉터리는 **생성 허용** — 본 skill의 출력 단위이므로.
- `assets/` 같은 이미지 디렉터리도 본 skill은 만들지 않는다. placeholder에 경로만 제시.

## 한 섹션 한 사이클 원칙

- 한 섹션에서 사용자에게 던지는 질문은 **1~3개**. 4개 이상 던지면 사용자 피로감으로 답변 누락.
- 사용자가 답변을 마치기 전에 다음 섹션으로 자동 진행 금지.
- 단, 사용자가 명시적으로 "이 섹션 placeholder로 두고 넘어가자"라고 하면 모든 미결 항목을 추가논의로 누적 후 다음 섹션.

## 외부 출처

- 시장 자료·통계는 가능한 한 **한국어 1차 출처**를 인용: KOSIS, 정보통신정책연구원(KISDI), 과기정통부, 통계청, 한국인터넷진흥원(KISA), 정보통신기획평가원(IITP) 등.
- 영어 출처를 그대로 본문에 인용하지 않는다. 출처 메모는 가능하지만 본문 문장은 한국어.
- 추측한 출처를 만들어내지 않는다. 출처가 의심되면 인라인 추가논의에 `[확인 필요]`.

## SWM 공식성 / 비공식성

- 본 레포는 SWM 운영진과 무관한 비공식 학습 툴이다. 산출한 기획서가 통과를 보장하지 않는다는 톤을 유지.
- "공식 평가 기준에 따르면…" 같은 단정 금지. RAW에 명시적 근거 없는 평가 기준 단정 금지.

## 다른 skill과의 관계

- `analyze-meeting`이 만든 `synthesis.md`는 **자동 첨부하지 않는다**. 사용자가 직접 `projects/inputs/<project>/` 로 복사해 넣어야 한다.
- `synthesis-framework` skill은 본 skill이 직접 호출하지 않는다. 마무리에서 사용자에게 `/analyze-meeting <project> planning` 후속 호출을 제안할 뿐.

## 에러 처리

| 상황 | 대응 |
| --- | --- |
| RAW DATA 0건 | [`invocation.md`](./invocation.md) 검증에 따라 중단. |
| RAW 합본이 단일 호출에 너무 큼 | 자동 축약·생략 금지. 사용자에게 "특정 기간/파일 범위로 좁힐지" 묻기. |
| `progress.json` 손상 | 사용자에게 알리고 "처음부터 다시 vs 손으로 수정" 선택. |
| 본문이 10p 초과 우려 | 사용자에게 "분량 조절 필요" 안내 + 어떤 섹션을 줄일지 의논. 자동 축약 금지. |
| 17섹션 진행 중 사용자가 "중단" | 즉시 `progress.json` 저장 후 종료. 다음 호출에서 `--resume`. |
| 17섹션 중 일부만 RAW로 채워짐 | 가능한 섹션은 채우고, 비는 섹션은 placeholder + 인라인 추가논의로 누적해 계속 진행. |
| 동일 ts 디렉터리 존재 (새 실행) | 접미사 `-2`, `-3` 부여. |

## 톤

- 격려·완곡어 금지. 외부 후기에서 자주 지적된 항목은 그 자리에서 직설적으로 짚는다.
- 단, 사용자(연수생 본인)의 의사결정을 빼앗지 않는다. 결정은 묻고, 결정 안 된 항목은 추가논의로 누적.
